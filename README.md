# MedTranslator

Frasi pronte per comunicare con i pazienti (infermieri, OSS, operatori alberghieri, medici).

© 2026 Massimiliano Previtali. Tutti i diritti riservati.

> Strumento di aiuto: non sostituisce il mediatore culturale né il consenso informato.
> Le traduzioni vanno controllate da madrelingua prima di usarle con i pazienti.

## Cosa fa

- **15 lingue**: italiano, inglese, spagnolo, francese, arabo, cinese, giapponese, urdu, romeno,
  albanese, punjabi, ucraino, russo, bengalese, tagalog.
- **Lingua dell'operatore**: tutta l'app (frasi, bottoni, argomenti, spiegazioni) nella lingua di chi assiste.
- **Frasi per ruolo**: ogni lavoro vede le sue; la ricerca e gli "Altri ruoli" mostrano anche quelle degli altri.
- **Il paziente risponde toccando**: Sì/No, scala del dolore 0-10, risposte con figure, tabella a immagini
  per chi non può parlare, scheda tè/caffè/camomilla.
- **Dizionario**: 118 parole singole in 9 categorie (esami, medicine, corpo, sintomi, luoghi, oggetti,
  persone, tempo, cibo), grandi a schermo e lette a voce.
- **Ricerca scritta e a voce** (microfono), con plurali e parole simili.
- **Voce** del telefono; se una lingua non ha la voce, il testo resta grande a schermo.

## Come avere l'app sul telefono (senza computer)

GitHub costruisce l'app da solo a ogni modifica:
GitHub → **Actions** → la riga più in alto, verde → in fondo **Artifacts** → **MedTranslator-app**.
L'app è firmata sempre con la stessa firma (`firma/`), quindi si **aggiorna sopra** la vecchia, senza disinstallare.

## Fogli di controllo delle traduzioni

Un file per lingua (frase italiana, traduzione, "Giusta" / "Da correggere"), da far compilare ai madrelingua.
